# Squid Rush

A Rive game by Danilo Fiocco. Play it at https://danilofiocco.github.io/squidRush/

`index.html` runs `squidGame.riv` (a signed build of the Rive CLI project) with the Rive web
runtime. `build.sh` rebuilds it from the project folder one level up. The shared leaderboard is
described in `LEADERBOARD.md`.
